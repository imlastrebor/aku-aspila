# Aku Aspila Website — Agent Instructions

## Goal
Build a framed, editorial personal website with a fixed rounded frame and scrollable inner content.

## Hard Rules
- The page background is solid color.
- The site content lives inside a vertically centered rounded frame.
- The frame is fixed.
- Only the content inside scrolls.
- No cards.
- No navigation bar.
- No hero image.
- Use illustration as hero visual.
- One accent color only.
- Minimal motion only (fade + slight translate).

## Stack
- React
- Tailwind CSS
- Framer Motion
- No UI libraries

## Layout Behavior
- Frame vertically centered
- Smooth scroll inside frame
- Frame keeps margins on mobile
- No full-bleed sections

## Design Priority
Poster-like composition.
Brand name must dominate first viewport.
